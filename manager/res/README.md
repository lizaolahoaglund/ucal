# UCAL identity assets

`ucal.png` is the blue code-bridge mark for UCAL. `ucal.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel images generated from that artwork with the [Manager branding tool](../tools/UcalBranding.pro). The PNG and ICO are source assets.

Manager uses the same mark for its executable, window, tray, navigation identity and Settings/About. Application shortcuts retain the installed software icon with a UCAL badge in the lower right corner. Composed icons are cached next to the portable workspace and are not plugin metadata. The shortcut still launches the selected application through UCAL Manager; it does not modify the vendor's original icon or install directory.
