# Source modules

- [UCAL](../ucal/doc/README.md): neutral contracts and runtime.
- [Manager](../manager/doc/README.md): Qt control plane.
- [Frontends](../frontends/README.md): consumer API and software integrations.
- [Backends](../backends/README.md): hardware runtime adapters.

Each optional module owns its source, singular `test`, documentation and metadata.
See [layout](layout.md), [coding conventions](coding_conventions.md) and
[regression entry points](../test/Running.md).
